# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a core focus of ResumeLens, especially regarding parser safety, memory boundaries, and document isolation.

If you discover a security vulnerability, please do **NOT** open a public issue. Instead, report it responsibly via:

1. **Email**: Contact the repository owner directly at **chiragdwivediji@gmail.com** with the subject line `[SECURITY] ResumeLens Vulnerability Report`.
2. **GitHub Private Vulnerability Advisory**: Use the "Report a vulnerability" button under the **Security** tab of the repository.

### What to Include in Your Report

- Detailed description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept (PoC).
- Any potential remediations or patches if available.

### Response Timeline

- **Acknowledgment**: Within 48 hours of receipt.
- **Assessment**: Within 5 business days, including confirmation of severity.
- **Resolution**: A coordinated patch will be released and credit will be acknowledged in the release notes.
